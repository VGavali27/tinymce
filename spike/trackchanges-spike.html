Self-hosted TinyMCE 8.9.3. Two editors run the same round-trip: A uses the default schema; B adds extended_valid_elements. “Run checks” does a setContent → getContent round-trip and reports whether ins / del / datetime / data-* survive serialization + xss_sanitization.

Then click into editor B, toggle live interception on, and type or press Backspace: typed characters are wrapped in a green <ins> (hover it), and deletions are suppressed. The report logs every beforeinput so you can see the mechanism.
